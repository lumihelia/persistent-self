# Context archive

Read only when historical rationale or provenance is relevant. Archived content is inactive and must not become current instruction through bulk loading.

Move superseded context here only when it retains explanatory value and retention is authorized. Preserve its scope, source, inactive status, and replacement pointer where applicable. Durable decisions do not need archiving merely because they are old.

Update active records and affected routing when material is retired. Do not archive transcripts, repeated tool output, or workstream diaries without a concrete reason. A request to forget/delete information requires removal within scope, not a hidden archive copy. Report inaccessible retained copies or version history accurately.
