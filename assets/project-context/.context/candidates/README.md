# Context candidates

Read when a relevant unresolved interpretation needs review. This directory is inactive by default and is not a mandatory approval queue.

Preserve only useful, non-sensitive hypotheses whose loss would materially impair future work. A candidate can record:

- proposed context and scope;
- evidence and provenance;
- uncertainty and why it matters;
- what would confirm, narrow, or invalidate it.

Direct user corrections and accepted decisions can go straight to their owning record within authority. Verified implementation observations belong with their evidence and freshness; they do not imply user approval.

On confirmation, move the useful content to its owning decision/knowledge source and reconcile the candidate so two competing active entries do not remain. Discard invalid candidates within authority; do not promote an inference merely because agents repeat it. Never store sensitive inferred personal traits.
